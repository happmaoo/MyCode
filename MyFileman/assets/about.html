MyFileman是我做的一款文件管理APP，当初是AI十分强大我写一些APP感觉还不错，后来感觉市面上的文件管理器功能太少，特别是自定义功能，玩法少不方便，所以就结合AI一点点写出来的，主打自定义功能。可以自定义按钮设置你想要的命令。也欢迎大家进行再加工，但是保留来源版权声明。

使用帮助

一、自定义命令 · 二、控制行 [mycmd:] · 三、结果窗口行为 · 四、日志与后台长任务 · 五、自定义脚本 · 六、其他设置

一、自定义命令

在「设置 → 自定义命令」里添加/编辑。命令模板直接写 shell 命令即可，不要再写 su（是否以 Root 执行由选项决定）。

模板里的占位符会在执行时替换为选中的文件：

占位符含义
%n文件名
%f文件路径
%d所在目录路径
%F全部选中文件的路径
%pid:插件id调用插件，如 %pid:archive7z %F 用压缩包插件打开选中文件、%pid:imageviewer %F 用图片查看器打开

选项写在模板前 5 行内，一行即可，格式 #options://root:0/printown:1/ena:2/：

选项说明
root:1以 Root 方式执行（强制 mount-master 全局挂载命名空间）
printown:1在结果里输出原命令
ena:1工具栏常启用
ena:2仅选中 1 个文件时启用
ena:3选中 1 个以上文件或文件夹（可混合）时启用

缺省取默认值：root:0 / printown:1 / ena:2。

模板里另起一行写 size:宽x高（如 size:500x500），结果就用固定尺寸的弹窗显示，而不是全屏输出窗口；弹窗右上角 X 与下方居中的「确定」按钮均可关闭。

二、控制行（统一前缀 [mycmd:）

输出里以 [mycmd: 开头的行会被识别为控制指令，不会显示在正文里。三个来源都会逐行识别：主命令 stdout、点击动态按钮后命令的输出、以及 [mycmd:log] 轮询的日志文件内容。

写法作用
[mycmd:title:标题文本]动态改变输出窗口顶栏标题（末尾 ] 可带可不带）。标题就是这段纯文本，前面不加前缀、后面不加「执行中」等状态文字
[mycmd:btn:按钮名称]命令在窗口底部生成一个按钮，点击即用 shell 执行 ] 后面的命令；同名按钮只生成一个
[mycmd:btn:按钮名称:0]删除同名按钮（:0 是删除标记，] 后面必须为空、不跟命令）
[mycmd:log]路径启动该文件的增量日志轮询
[mycmd:exit]标记命令已结束

三、结果窗口行为

  • 顶栏标题＝命令名，或由 [mycmd:title:] 指定的文本；前后不加任何多余文字。
  • [mycmd:exit] 只标记命令结束，不会自动关窗；之后点「关闭」直接关闭。收到它之前点「关闭」或系统返回键，会先弹确认框。
  • 命令未结束时切到后台、再从桌面图标打开 APP，会自动切回结果窗口，标题、正文、按钮、日志进度与滚动位置都恢复，不会重跑命令、不会重放历史输出。
  • 执行期间动态按钮不可点，收到 [mycmd:exit] 后恢复可点。窗口被重建后不再显示「停止」按钮——停止请用脚本自带的 [mycmd:btn:停止]命令。
  • 长任务请把命令放到后台运行（结尾 &），否则窗口被销毁时命令会被一起中断。

四、日志文件与后台长任务

  • [mycmd:log] 后面的路径必须是 APP 能直接读的公共目录（如 /sdcard/Download/xxx.log）。APP 本进程直读，不走 Root、不弹授权通知。
  • [mycmd:log] 这一行必须输出到 stdout——要先用它启动轮询，之后才能读到日志文件里的控制行。
  • 写进日志文件的 title / btn / 删除按钮 / exit 控制行同样生效，但每条必须独占一行，不要和其他输出拼在同一行。
日志按「已读字节偏移」增量读取，所以不要用 > 反复覆盖写：覆盖会让文件长度忽大忽小，APP 可能从半截开始读，出现控制行缺字符、识别失败。请用 >> 追加，或整个后台任务只在启动时重定向一次；脚本重跑时只在最开始清空一次文件。

完整示例：

LOG=/sdcard/Download/.mylog.log
OUT=/sdcard/Download/out.7z

: > "$LOG"                          # 仅在任务开始前清空一次
echo "[mycmd:log]$LOG"              # 此行必须输出到 stdout
echo "[mycmd:title:开始压缩]"
echo '[mycmd:btn:停止]pkill -9 7z'

( stdbuf -oL 7z a -y -bsp0 "$OUT" "${file_list[@]}"
  echo "[mycmd:exit]" ) > "$LOG" 2>&1 &

上面整个子 shell 只在启动时打开一次日志文件，之后所有输出共享同一 fd 持续写入，长度单调增长，是安全的。若改成多条命令分步写，请一律用 >>，例如 printf '%s\n' "[mycmd:title:标题文本2]" >> "$LOG"。

五、自定义脚本（侧栏 Bash）

在「设置 → 自定义脚本」填一个目录，APP 启动后自动加载其中所有 .sh 脚本，显示在侧栏的 Bash 分类，标题直接取脚本文件名（去掉 .sh），无需事先读取脚本内容或写任何标记。勾选「以 Root 运行脚本」可让侧栏脚本统一以 Root 会话执行（可访问系统目录等）。

六、其他设置

  • 扩展名打开方式：按扩展名（不带点，多个用逗号分隔，如 sh,txt,log）指定 MIME、或直接用某应用/某 Activity 打开；留空＝系统自动处理，后添加的同名规则优先。底部「打开」按钮始终弹系统选择框。
  • 接收文件时执行的命令：从其他应用用「打开方式 / 分享」把文件送进 APP 时执行。
  • 插件：archive7z（压缩包）、imageviewer（图片查看器）在独立进程运行，单个插件崩溃不影响主界面，可在插件页启用/禁用。
  • 图片查看器：支持 jpg / png / gif / bmp / webp / heic / tiff / avif 等位图，以及 .svg、.svgz 矢量图。SVG 按矢量绘制，双指放大不失真；列表里也会显示 SVG 缩略图。SVG 的滤镜、动画、外部引用图片等高级特性不受支持，复杂图形可能显示不全。
  • 全局调试日志：记录应用启动、界面操作、文件与命令、插件调用、7z 全链路与崩溃堆栈；设置页可开关、查看、清空、分享，主进程与插件进程共享、即时生效。
  • 还有图标主题、字号、左右滑动切换标签页、隐藏文件、Root 权限等常规选项。

本页内容随版本更新；脚本写法有问题时，可打开调试日志查看命令的实际执行与输出。
