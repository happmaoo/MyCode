图标主题来源与许可（MyFileman）
================================================
本 APK 内置 2 套图标主题，均为第三方开源项目，图标版权归各自作者所有。
如要对外分发本 APK，请自行核对并遵守各主题的许可条款。

1) elementary  assets/elementary/  （应用默认主题）
   来源: 用户上传的 icon-elementary.zip（mimes/128，文件类型图标）
        与 places.zip（places/128，文件夹/返回上级图标）
   许可: elementary 图标主题通常为 GPL-3.0；上传包内未附 LICENSE，请自行确认
   说明: 主题目录含 0~11.png 粗分类位图与 mimes/ 子目录
        （150 张按扩展名精确匹配的图标），详见下面第 7 节。

2) Adwaita (GNOME)  assets/adwaita/
   来源: https://github.com/GNOME/adwaita-icon-theme
   许可: LGPL-3 或 CC-BY-SA 3.0
   说明: 主题目录含 0~11.png 粗分类位图与 mimes/ 子目录
        （27 张按文件类型精确匹配的图标，取自官方包 scalable/mimetypes）。

说明: 每套主题按文件类型编号 0~11 各存放一张 128x128 透明 PNG。
     仅截取所需图标用于界面展示，未改动图标本身；SVG 已渲染为位图。
     早期版本曾内置扁平单色（纯代码绘制）、Papirus、Qogir、Windows 98、
     KDE Oxygen、KDE Breeze 六套主题及其资源，现已全部移除。

3) 工具栏图标  assets/ui/  （29 张 96x96 透明 PNG）
   来源: 用户上传的 icon-elementary-xfce.zip（elementary-xfce 图标主题）
   许可: elementary 系列图标主题通常为 GPL-3.0；上传包内仅含 README.md 与
        index.theme，未附 LICENSE 文件，请自行确认许可后再对外分发。
   用途: 主界面顶部栏、地址栏、工具栏、底部操作栏、命令行按钮；多数按 22dp 显示，
        工具栏下拉菜单触发按钮与菜单项图标按 18~20dp 显示。
   说明: 图标经 SVG 渲染为位图，未改动图形本身；界面按钮文字改为图标，长按显示名称提示。
        「自定义命令」按钮保留命令名文字，仅在文字前加一枚图标。

4) 两套主题的精确文件类型图标  assets/elementary/mimes/ 与 assets/adwaita/mimes/
   来源: elementary —— 用户上传的 128.7z（mimes/128，150 个 SVG 文件类型图标；
        与 elementary 主题同源，已确认通用图标与原有位图完全一致）
        Adwaita —— /usr/share/icons/Adwaita/scalable/mimetypes/（官方包内置
        27 个 MIME 图标，仅覆盖常见大类，缺失项自动回退 elementary）
   许可: 分别随各自图标主题（elementary 通常为 GPL-3.0；Adwaita 为 LGPL-3 或
        CC-BY-SA 3.0）；elementary 上传包未附 LICENSE，请自行确认
   用途: 按扩展名/文件名精确显示（pdf / 7z / py / docx / mp4 / jar ...）。
        目录、上级目录与未收录类型仍回退到各自主题的 0~11.png 粗分类位图；
        Adwaita 缺某精确图标时回退 elementary 的同名图标。
   说明: SVG 由 rsvg-convert 渲染为 128x128 透明 PNG，未改动图形本身。

5) 用户补充上传的 3 张 SVG（2026-11-13）
   来源: edit-find.svg、view-grid-symbolic.svg、view-list-symbolic.svg
        （elementary / symbolic 风格，与上面第 1、2 节主题同源）
   许可: 上传文件未附 LICENSE，请自行确认许可后再对外分发。
   用途: edit-find.svg 渲染后替换 assets/ui/search.png（工具栏「搜索」图标）；
        view-grid-symbolic.svg / view-list-symbolic.svg 渲染为 assets/ui/viewGrid.png、
        viewList.png，用于工具栏「视图切换」按钮，运行时按当前着重色着色。
   说明: 均由 cairosvg 渲染为 96x96 透明 PNG，未改动图形本身。

   许可: 上传文件未附 LICENSE，请自行确认许可后再对外分发。
   用途: 渲染为 assets/ui/sort.png，用于工具栏「排序」按钮（图标 + 右侧小三角）；
