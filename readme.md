## MyFileman 强大的文件管理器
可以自定义很多命令，bash命令等等，建议配合root 和 termux 使用.
配合termux和root后可以直接查看压缩包内容，复制压缩包文件，速度一流。
自定义脚本，自定义文件打开方式，支持主题图标更换，自定义界面字体.
适合喜欢折腾手机一族。
https://github.com/happmaoo/MyCode/tree/main/MyFileman/

## WifiDirectShare wifi快速文件互传
利用 Wifi Direct 发送文件，打开app自动连接指定的设备，支持发送文件夹，支持文件管理器里分享到发送到对方设备。
https://github.com/happmaoo/MyCode/tree/main/WifiDirectShare/

## autobrightness 亮度调节
MIUI的亮度调节不好用，于是就自己写一个，目前很不错。  
首先需要权限里设置允许修改系统设置。  
2025.12.30 全线更新2.0版本，调节更灵敏优化算法，不卡顿  
2026.01.28 修复bug  
2026.11.17 修复bug  
https://github.com/happmaoo/MyCode/tree/main/autobrightness/

## clockwidget 一个最简洁的桌面时钟小部件
简洁，省资源，没有联网啥乱七八糟的权限。  
https://github.com/happmaoo/MyCode/tree/main/clockwidget/app/release

## MyBle 蓝牙ble工具
内含多个程序和APP 用于蓝牙ble和蓝牙pan 蓝牙共享网络连接
配合termux使用可以运行bash命令，编辑文件，上传和下载文件。
不得不说有了ai就是厉害，代码都不用写了。
https://github.com/happmaoo/MyCode/tree/main/MyBle 

## MyBleCam ble蓝牙摄像头
ble速度有限，玩玩还是不错的
https://github.com/happmaoo/MyCode/tree/main/MyBleCam

## MyBtCam 蓝牙摄像头
经典蓝牙协议，支持摄像头切换，开机自启动，分辨率，码率调整。
https://github.com/happmaoo/MyCode/tree/main/MyBtCam

## MyFM 红米Note4x 的收音机APP
红米Note4x和lineageOS自带的收音机不好用，自己写的代码，需要root，我的机子是 lineageOS 15.1 安卓8.1版本，可能其他高版本不能使用请自己测试。  
https://github.com/happmaoo/MyCode/tree/main/MyFM/app/release

## MyDeskNote 超小的桌面便签APP
功能简单，可以设置字体大小，可以很小，不占用桌面空间。  
https://github.com/happmaoo/MyCode/tree/main/MyDeskNote/

## MyAudioRecorder 录音机，可以手机录音也可以同一WIFI下电脑录音代替麦克风
一个简单的录音APP，本地和网络传输录音  
https://github.com/happmaoo/MyCode/tree/main/MyAudioRecorder/app/release

## MyMQTT 可用于物联网卡小服务器APP控制
